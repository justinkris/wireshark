Review Questions
Official WCNA exam-style review questions from Chapter 12. Write your answer before revealing the model answer.
Q12.1

How can you quickly view all the packet comments in a trace file?

Your Answer
Model Answer
Open the Expert Infos window (Analyze | Expert Info or click the Expert Info button on the Status Bar) and select the Packet Comments tab. This lists all packet annotations in the trace file in one place.
Q12.2

What save options are available when you only want to save a subset of packets contained in a trace file?

Your Answer
Model Answer
When you select File | Export Specified Packets, you can choose to save: displayed packets only (matching current display filter), selected packet, marked packets, first to last marked packets, or a specific packet range. This allows you to extract just the relevant packets from a large trace file.
Q12.3

What export format could you use if you are going to import information from the Packet List pane into a spreadsheet program?

Your Answer
Model Answer
Comma Separated Value (CSV) format imports easily into spreadsheet programs like Excel. Select File | Export Packet Dissections | As CSV... to save the current Packet List pane columns as a CSV file. Make sure you have added any custom columns you want before exporting.
Q12.4

Which Wireshark feature should you use if you want to save a TCP header as a text file?

Your Answer
Model Answer
Expand the TCP header in a packet in the Packet Details pane, then choose File | Export Packet Dissections and choose to export as 'Plain Text' file. Select Packet Details: As displayed in the Packet Format section to capture the expanded TCP header fields as text.
