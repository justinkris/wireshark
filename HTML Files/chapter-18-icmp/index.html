    Chapter 18: ICMP

    Chapter 18 examines ICMP — the Internet Control Message Protocol used for diagnostics, error reporting, and network management. You'll analyze ping sequences, ICMP redirects, and unreachable messages to understand how routers communicate path problems.

    Guided Analysis — icmp-ping-basic.pcapng
    Trace: icmp-ping-basic.pcapng — Q1
    Open icmp-ping-basic.pcapng. Apply filter icmp. Identify the ICMP Type and Code for the Echo Request and Echo Reply packets. What is the difference between the two?
    Echo Request is ICMP Type 8, Code 0. Echo Reply is ICMP Type 0, Code 0. The request travels from the pinging host to the target; the reply travels back. The Type field distinguishes the direction — both carry the same sequence number and identifier so they can be matched.
    Trace: icmp-ping-basic.pcapng — Q2
    Examine the ICMP sequence numbers across multiple ping packets. Do they increment by 1 with each request/reply pair? What would a missing sequence number in the replies indicate?
    Yes, ICMP sequence numbers increment by 1 for each Echo Request. If a reply is missing for a particular sequence number, that specific packet was lost in transit, indicating packet loss on the path to the destination — useful for diagnosing intermittent connectivity issues.
    Guided Analysis — icmp-redirects.pcapng
    Trace: icmp-redirects.pcapng — Q1
    Open icmp-redirects.pcapng. Apply filter icmp.type == 5. What does an ICMP Redirect message tell the sender, and which device sends it?
    A router sends ICMP Type 5 (Redirect) to a host when it forwards a packet out the same interface it arrived on — meaning the host should be using a better (more direct) gateway. The message tells the source host to update its routing table to use a more optimal next-hop for that destination.
    Trace: icmp-redirects.pcapng — Q2
    Look at the ICMP Redirect message details. What information does the redirect carry to help the source host update its routing? What Code value indicates a redirect for a host (vs. a network)?
    The ICMP Redirect carries the IP address of the better gateway the host should use. Code 0 = redirect for the network, Code 1 = redirect for the host (most specific). Code 1 redirects tell the sender to use a specific next-hop for that particular destination IP going forward.

    Review Questions
    Review Q18.1
    List four common ICMP message types and their type numbers.
    Type 0: Echo Reply (ping response). Type 3: Destination Unreachable (with various codes for host/port/network unreachable). Type 5: Redirect (better route available). Type 8: Echo Request (ping). Type 11: Time Exceeded (TTL expired). Memorize these — they appear on WCNA exam questions about ICMP behavior.
    Review Q18.2
    What is the difference between ICMP Type 3 Code 0 and Type 3 Code 3?
    ICMP Type 3 Code 0 means Network Unreachable — a router cannot find a route to the destination network. Code 3 means Port Unreachable — the destination host received the packet but no application is listening on the target port (common with UDP). Code 1 is Host Unreachable (router can't reach the host on the local segment).
    Review Q18.3
    How would you use Wireshark to measure the round-trip time of ICMP ping packets?
    Look at the time delta between an ICMP Echo Request (Type 8) and its matching Echo Reply (Type 0) — they share the same Identifier and Sequence number. In Wireshark, set the time display to 'Seconds Since Previous Displayed Packet' or use a calculated field; the delta on each Reply frame is the RTT for that probe.

    Quick Reference

    ICMP Type 8 / Type 0
    Echo Request / Echo Reply — the ping pair. Match by Identifier + Sequence.
    ICMP Type 3
    Destination Unreachable. Code 0=Network, Code 1=Host, Code 3=Port unreachable.
    ICMP Type 5
    Redirect — router tells host to use a better next-hop gateway.
    ICMP Type 11
    Time Exceeded — TTL reached 0 at a router; used by traceroute.
