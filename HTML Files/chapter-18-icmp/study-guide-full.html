💭THINK FIRST · ICMP PURPOSE & BEHAVIOR

ICMP is a messaging layer for IP — it reports errors, provides echo tests, and signals routing information. Because ICMP packets carry no TCP or UDP header, port-based filters cannot block them. Many ICMP packets include a copy of the original IP header and first 8 bytes of the packet that triggered the ICMP response.

  • ICMP Destination Unreachable (Type 3) responses to TCP handshake SYN packets are unusual. What does this suggest about the target, and why is it different from a TCP RST response?
  • Why should you never block ICMP Type 3, Code 4 (Fragmentation Needed) packets on a firewall?

Model Answer 1: A TCP RST means the target host is reachable, the TCP stack is working, and the port is simply closed. An ICMP Destination Unreachable response to a TCP SYN suggests the target port is firewalled — a host-based or network firewall is intercepting and generating the ICMP response rather than the TCP stack itself. This is more unusual because a well-configured firewall would silently discard (not announce with an ICMP) the packet.

Model Answer 2: ICMP Type 3 Code 4 is the Path MTU Discovery mechanism. When a router must fragment a packet with the Don't Fragment bit set, it sends this ICMP message back to the source indicating the maximum MTU on the next link. If this ICMP is blocked, the source never learns about the MTU limitation, keeps sending oversized packets, and the connection hangs silently — the "black hole" problem. Without these ICMP messages, MTU discovery is impossible and file transfers above the fragmented MTU size will fail.

The Purpose of ICMP

ICMP is used as a messaging system for errors, alerts, and general notifications on an IP network. ICMP is defined in RFC 792. ICMP packets do not contain a UDP or TCP header — port filtering cannot affect ICMP traffic.

Key ICMP message categories:

  • Echo messages (Type 8/0): Used by ping and traceroute. Too many may signal reconnaissance or DoS.
  • Redirect messages (Type 5): Used by routers to indicate a better path. If NOT sent by a router, consider it suspect.
  • Destination Unreachable messages (Type 3): Explain why a packet could not be delivered. Many of these could indicate a UDP port scan or a misconfigured service.

💭THINK FIRST · ICMP TYPES & CODES

ICMP packet types define the category of message; the Code field provides detail within that type. Type 3 (Destination Unreachable) has 16 different codes. Understanding which codes indicate which kind of failure lets you pinpoint the problem without moving the analyzer.

  • ICMP Type 3 Code 1 (Host Unreachable) versus Code 3 (Port Unreachable): what infrastructure element is likely generating each, and what does it tell you about the path?

Model Answer: Code 1 (Host Unreachable) is generated by a router that knows about the network but cannot reach the specific host — it sent an ARP broadcast for the host and got no reply. This means the packet arrived at the right network, but the host isn't up or isn't responding to ARP. Code 3 (Port Unreachable) is generated by the destination host itself — the host received the packet and its IP/transport stack processed it, but no application is listening on that UDP port. Code 3 on a TCP SYN indicates a firewall is generating the response, since TCP connections should trigger RST, not ICMP.

ICMP Types & Codes

ICMP packets only require three fields after the IP header: Type, Code, and Checksum. Some packets contain additional fields.

💭THINK FIRST · ICMPv6

ICMPv6 expands on ICMP's role significantly. In IPv6, ICMPv6 handles not only error reporting and echo, but also neighbor discovery (replacing ARP), duplicate address detection, and router discovery. ICMPv6 Echo uses Types 128/129 instead of 8/0.

  • ICMPv6 Neighbor Solicitation (Type 135) sent from source address :: has a special meaning. What is it, and which IPv4 mechanism does it correspond to?

Model Answer: Source address :: (the unspecified address) in a Neighbor Solicitation means the host doesn't yet have an IPv6 address and is performing Duplicate Address Detection (DAD) — it's asking "is anyone already using this address?" before configuring it. This is the ICMPv6 equivalent of a gratuitous ARP in IPv4, where a host sets both source and target IP to its own address to check for conflicts. Both serve the same purpose: verifying address uniqueness before putting the address into service.

Basic ICMPv6 Functionality

RFC 4443 defines ICMPv6. The packet structure is the same as ICMP. ICMPv6 plays several critical roles in IPv6 communications:

3Time ExceededCode 0: Hop limit exceeded. Code 1: Fragment reassembly timeout.

Case Studies

Case Study 1
The Dead-End Router
Submitted by: Laura Chappell

A customer complained that some of their hosts could not reach the internet on certain days — rebooting workstations would fix it temporarily.

The traffic showed the clients transmitting ICMPv6 Router Solicitations because the default gateway provided by the DHCP server did not reside on the local network. An accounting server (a Sun host) was configured to respond with Router Advertisements. That Sun host was not actually a router.

If the Sun host's Router Advertisement arrived before the Cisco router's Router Advertisement, the client used the Sun host's IP address as its default gateway. When the clients needed to communicate with hosts on other networks, packets were sent to the Sun box — and discarded, because it didn't offer routing services.

It was easy to spot the problem in just a few minutes by examining the ICMP/ICMPv6 traffic and noticing the non-router was sending Router Advertisements.

TL;DR — Chapter Summary

ICMP offers a messaging service to indicate network configuration problems, unavailable services, hosts that are too far away, fragmentation problems and more. ICMP packets do not contain TCP or UDP headers — port filtering cannot block ICMP traffic.

Many ICMP packets contain the original IP header that triggered the ICMP packet. ICMP Echo Requests are commonly used for ping tests and traceroute operations.

ICMPv6 plays several very important roles in IPv6 communications including duplicate address detection (Type 135 from ::), neighbor discovery, router solicitation/advertisement, and error reporting. ICMPv6 Echo uses Types 128/129.

Review Questions

Q18.1 What is the purpose of ICMP?
A18.1 ICMP is used as a messaging system for errors, alerts, and general notifications on an IP network.
Q18.2 What type of device might generate an ICMP Type 3, Code 13 (Destination Unreachable, Communication Administratively Prohibited) packet?
A18.2 This packet might be generated by a verbose firewall. Many firewalls will silently discard blocked packets rather than send this response.
Q18.3 You have captured only ICMP packets. How can you determine what triggered the ICMP Type 3 (Destination Unreachable) packets?
A18.3 ICMP Type 3 packets contain the IP header and at least the next 8 bytes of the packet that triggered the response. Examine the IP header and bytes following the ICMP portion to determine why this packet was sent.
Q18.4 Which ICMPv4 and ICMPv6 packets are used for the standard ICMP-based ping process?
A18.4 ICMPv4: Type 8 (Echo Request) and Type 0 (Echo Reply). ICMPv6: Type 128 (Echo Request) and Type 129 (Echo Reply).
Q18.5 What should a host do when it receives an ICMP Type 5, Code 0 (Redirect Datagram for the Network) packet?
A18.5 The host should update its routing tables with the gateway address included in the ICMP packet and use the new gateway entry for future communications to that network.
Q18.6 What is the syntax for capture and display filters for ICMPv4 and ICMPv6 traffic?
A18.6 Capture: icmp (IPv4) or icmp6 (IPv6). Display: icmp (IPv4) or icmpv6 (IPv6).
Q18.7 What ICMPv6 packet is used to check for duplicate IP address assignment?
A18.7 ICMPv6 Neighbor Solicitation (Type 135) sent from source address :: (unspecified) is used for Duplicate Address Detection (DAD).
