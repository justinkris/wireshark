Find the following answers using the information contained in this chapter:

Each of these items can be determined through the Wireshark Status Bar or Main Menu system.

Q1

What is the highest level of Expert Information contained in this trace file?

Your Answer
Model Answer
Check the Expert Info button on the Status Bar (bottom-left of the Wireshark window). The color indicates the highest severity level present: Red = Errors, Yellow = Warnings, Cyan = Notes, Blue = Chats. In ftp-dir.enc look at the Expert Info button color to determine the highest level. You can also click the button to open the Expert Infos window and see all events grouped by severity.
Q2

What profile has been applied?

Your Answer
Model Answer
The active profile is displayed in the bottom-right corner of the Status Bar. It shows the profile name (e.g., "Profile: Default"). If you have not created any custom profiles, it will show "Default." You can click on the Profile column in the Status Bar to switch between available profiles.
Q3

What is the time display format setting?

Your Answer
Model Answer
Check the Time column in the Packet List pane to see which format is active. The default is "Seconds since beginning of capture" (RELATIVE). You can change it via View | Time Display Format. Options include Relative, Absolute, Delta (time since previous packet), Epoch and more. The current setting is saved in Wireshark's preferences/profile.
Q4

Did Wireshark resolve IP addresses to names?

Your Answer
Model Answer
Look at the Source and Destination columns in the Packet List pane. If IP addresses appear as hostnames (e.g., "www.google.com" instead of "74.125.19.147"), then network name resolution is enabled. Check Edit | Preferences | Name Resolution or View | Name Resolution to see the current settings. Name resolution is controlled independently for MAC addresses, network (IP) addresses, and transport (port) names.
Q5

How many capture interfaces are currently available on your system?

Your Answer
Model Answer
Select Capture | Interfaces or click the interface list icon on the toolbar to see all available capture interfaces. The number varies by system. On a typical laptop you might see 2-4 interfaces (wired Ethernet, Wi-Fi, loopback, and possibly virtual adapters). The Capture Interfaces window shows each interface's name and current packet rate—useful for identifying the busiest interface before you start capturing.

Review Questions
Official WCNA exam-style review questions from the end of Chapter 2. Write your answer before revealing the model answer.
Q2.1

What is the purpose of WinPcap?

Your Answer
Model Answer
WinPcap is the Windows port of the libpcap link-layer interface. WinPcap provides the low-level network access for packet capture on a Windows host.
Q2.2

What is the purpose of Wireshark's dissectors?

Your Answer
Model Answer
Wireshark dissectors decode packets to display field contents and interpreted values (if available). An HTTP packet will use several dissectors — Ethernet, IP, TCP and HTTP — each decoding its own protocol layer.
Q2.3

What is the purpose of the Wiretap library?

Your Answer
Model Answer
The Wireshark Wiretap Library enables Wireshark to read a variety of trace file formats such as the formats used by Microsoft's Network Monitor, Network General Sniffer and WildPackets OmniPeek products. It acts as a universal file format translation layer.
