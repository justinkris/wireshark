Create and Apply a Capture Filter for Your Own Traffic

Task 1

Create and save a "My MAC" capture filter based on your own hardware address. Open Capture | Capture Filters, click New, enter the filter name "My MAC" and the filter string ether host xx:xx:xx:xx:xx:xx (replace with your actual MAC address). Click OK to save.

My Notes
Task 2

Start capturing your traffic using the "My MAC" capture filter. Do not touch your keyboard for at least 5 minutes. Did you capture any traffic? The packets would be generated by automated processes running in the background on your computer.

Task 3

Try another test — using the "My MAC" filter, browse to www.wireshark.org. Do not navigate through the site — just browse to the main page. Stop capturing and examine the traffic you captured. If your browser performs site safety checks or the Wireshark site drops cookies on your drive, it will be visible in your trace file.

Review Questions
Official WCNA exam-style review questions from the end of Chapter 4. Write your answer before revealing the model answer.
Q4.1

What is the difference between capture filters and display filters?

Your Answer
Model Answer
Capture filters are applied to traffic during the capture process only — they cannot be applied to existing trace files and packets that don't match are permanently discarded. Display filters can be used while capturing but do not limit which packets are saved — they only control what is visible. Display filters can be applied to existing trace files. Each type uses a different syntax: capture filters use BPF, display filters use Wireshark's own syntax.
Q4.2

What format is used by Wireshark's capture filters?

Your Answer
Model Answer
Capture filters use the Berkeley Packet Filtering (BPF) filter syntax — the same syntax used by tcpdump. This is different from Wireshark's display filter syntax. BPF uses primitives such as host, port, net, ether, and qualifiers (type, direction, protocol) to build filter expressions.
Q4.3

What is the purpose of the following capture filters?

ether dst 08:3f:3d:03:32:03
gateway rtrmain01
host www.espn.com

Your Answer
Model Answer
ether dst 08:3f:3d:03:32:03 — Captures all traffic sent to the Ethernet address 08:3f:3d:03:32:03 (unidirectional — destination only).

gateway rtrmain01 — Captures traffic to or from the hardware address of rtrmain01, but not to the IP address of rtrmain01. Requires the host name to be resolvable. Effectively captures routed traffic passing through that gateway.

host www.espn.com — Captures traffic to or from the IP address associated with www.espn.com. If the site redirects to another URL, traffic to that redirect destination won't be captured by this filter.
