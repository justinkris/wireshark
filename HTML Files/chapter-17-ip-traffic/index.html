    Chapter 17: IP Traffic

    Chapter 17 covers IPv4 and IPv6 packet structure, fragmentation, TTL behavior, and common IP anomalies. You'll examine smurf attacks, TTL-expiry traces, and overlapping IP fragments using Wireshark filters.

    Guided Analysis — ip-smurf.pcapng
    Trace: ip-smurf.pcapng — Q1
    Open ip-smurf.pcapng. A smurf attack sends ICMP Echo Requests to a broadcast address with a spoofed source IP. Apply filter icmp. What do you notice about the destination IP addresses of the ICMP Echo Requests? What is the source IP?
    The ICMP Echo Requests are sent to a broadcast address (e.g., x.x.x.255 or the subnet broadcast). The source IP is spoofed — it belongs to the victim host, so all the broadcast replies flood the victim. This is the hallmark of a smurf amplification attack.
    Trace: ip-smurf.pcapng — Q2
    Apply the filter ip.dst == 10.2.2.2 (or the victim's IP). How many ICMP Echo Reply packets are directed at the victim per original request? What does this say about the amplification factor?
    Each broadcast ICMP Echo Request generates one reply per host that responds on the subnet. With dozens of hosts replying, the amplification factor equals the number of responding hosts — potentially 50–100×. This floods the victim with unsolicited traffic it never requested.
    Guided Analysis — ip-ttlexpiry.pcapng
    Trace: ip-ttlexpiry.pcapng — Q1
    Open ip-ttlexpiry.pcapng. Apply filter icmp.type == 11 (ICMP Time-to-Live Exceeded). What device sends these messages, and what do they indicate about the packet's journey?
    Routers send ICMP Type 11 (Time Exceeded) messages when a packet's TTL reaches zero before arriving at the destination. These packets indicate that the original packet was forwarded too many hops or the TTL was set too low, and a router discarded it and sent back the notification.
    Trace: ip-ttlexpiry.pcapng — Q2
    Examine the IP TTL field of the original packets (before TTL expiry). What starting TTL value is used? Knowing that each router decrements TTL by 1, how many hops did the packet travel before being dropped?
    If the original TTL is 1, the packet is dropped at the first router. If it's set higher (e.g., 64), count the hops shown by successive ICMP Time Exceeded messages. Tools like traceroute deliberately use incrementing TTL values starting at 1 to map each hop along the path.

    Review Questions
    Review Q17.1
    What is the purpose of the IP Time-to-Live (TTL) field, and what happens when it reaches zero?
    TTL limits a packet's lifetime in the network by decrementing by 1 at each router hop. When TTL reaches zero, the router discards the packet and sends an ICMP Type 11 (Time Exceeded) message back to the source, preventing packets from circling indefinitely due to routing loops.
    Review Q17.2
    How does IP fragmentation work, and what filter in Wireshark isolates fragmented packets?
    When a packet exceeds the MTU of a link, IP fragments it into smaller pieces, each carrying the original IP header plus a fragment offset indicating its position in the original datagram. The receiving host reassembles fragments using the IP ID, flags, and offset fields. The Wireshark filter ip.flags.mf == 1 || ip.frag_offset > 0 isolates all fragments.
    Review Q17.3
    Describe how a smurf attack works and which Wireshark filter would help you identify victim traffic.
    A smurf attack sends ICMP Echo Requests to a broadcast address with the victim's IP as the spoofed source. Every host on the subnet replies directly to the victim, overwhelming it. The filter icmp.type == 0 && ip.dst == [victim-ip] isolates the flood of Echo Replies hammering the victim.

    Quick Reference

    TTL (Time-to-Live)
    IP field decremented by 1 at each router; packet discarded and ICMP Type 11 sent when it reaches 0.
    IP Fragmentation
    Splitting packets exceeding link MTU; reassembled by destination using IP ID + fragment offset.
    Smurf Attack
    ICMP broadcast amplification with spoofed source; every host on subnet replies to victim.
